# 🌱 SIH Khet Drishti

## Smart IoT-Based Farm Monitoring & Crop Health Decision Support System

### 📌 Problem
Limited real-time farm visibility leads to delayed crop-health detection and inefficient resource management.

### 💡 Solution
Khet Drishti combines multi-zone IoT monitoring, MQTT communication, crop-health analysis, and a farmer decision-support dashboard.

### 🔄 System Architecture

Sensor Nodes
↓
MQTT Broker
↓
ESP32 Gateway
↓
Smart Dashboard
↓
Farmer Decision Center

### ⚙️ Technologies
- ESP32 / ESP32-S3
- Soil Moisture Sensor
- DHT22
- Wi-Fi
- MQTT
- Arduino C++
- HTML / CSS / JavaScript
- Wokwi

### 📊 Features
- Multi-zone farm monitoring
- Real-time soil moisture monitoring
- Temperature and humidity monitoring
- Crop-health analysis
- MQTT-based communication
- Smart dashboard
- Farmer decision support

### 🎯 Key Benefits
- Early awareness of crop-health issues
- Real-time farm visibility
- Better resource management
- Data-driven farmer decisions
- Scalable multi-zone architecture

### 🚀 Project Status
Prototype / SIH demonstration project.

### 👨‍🌾 Decision Support
The system provides information and recommendations to support the farmer.
Final agricultural action remains with the farmer.
